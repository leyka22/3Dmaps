# 3Dmaps — Санкт-Петербург

Адаптивный лендинг и интерактивная 3D-карта Санкт-Петербурга. Чистые HTML, CSS и JavaScript, без сборки и API-ключей.

## Запуск

Требуется Node.js 18+. Выполните `node server.mjs`, затем откройте http://localhost:4173.

Для любого статического хостинга публикуйте папку `dist`. Настройка Sites хранится в `.openai/hosting.json`.

## Возможности

- Объёмные здания, вращение, масштабирование, переключение 2D/3D.
- Дневной и ночной стили, шесть мест с карточками и маркерами.
- Поиск по авторской подборке (не адресный поиск), фильтры категорий.
- Ссылка с координатами, масштабом, вращением, наклоном и стилем.
- Полноэкранный интерфейс, клавиатурная навигация, reduced motion и мобильная версия.

## Данные и ограничения

MapLibre GL JS 5.6.1 (BSD-3-Clause), стили и тайлы OpenFreeMap, геоданные © OpenStreetMap contributors (ODbL), схема OpenMapTiles. Ссылки на атрибуцию доступны на карте и в футере. Для запуска нужны интернет и WebGL. Подключения: unpkg.com, tiles.openfreemap.org, fonts.googleapis.com, fonts.gstatic.com.

Камера ограничена прямоугольником городской области Санкт-Петербурга (29.4–30.8 E, 59.6–60.15 N); это не точный административный полигон, на краях видны прилегающие территории. Здания — экструзии контуров по данным OSM, а не фотограмметрия. При отсутствии высоты используется условная высота 8 м. Полнота и точность зависят от исходных данных. Карточки содержат авторские схематические SVG-иллюстрации, не фотографии.

## Проверка

`node --check dist/app.js` и `node --check server.mjs`. В браузере: загрузка карты, 3D-здания, оба стиля, 2D, поиск с пустым результатом, фильтры, шесть маркеров, открытие ссылки с ракурсом, Escape, Ctrl/Cmd+K, мобильная ширина 390 px.
